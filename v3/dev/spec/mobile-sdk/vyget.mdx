## Signature

<CodeGroup>

```kotlin Android
fun vyget(context: Context? = null): VyResult?
```

```swift iOS
static func vyget() -> VyResult?
```

```ts React Native
function vyget(): Promise<VyResult | null>;
```

</CodeGroup>

Returns the last result `onComplete` delivered, or `null`/`nil` if nothing has completed yet in this process. Never throws.

## Platform difference, named plainly

Android's `vyget()` takes an optional `Context`. Pass one and it recovers the last result from disk if the app's process was killed and restarted between the check completing and you calling `vyget()`, a real scenario: a camera permission dialog plus low memory can take the process down mid-flow. iOS and React Native hold the last result in memory only; neither survives a process restart today. If you need the result to survive one, confirm the token against your server as soon as `onComplete` fires rather than relying on `vyget()` later.

## Returns

| Situation | Result |
| --- | --- |
| A run completed in this process | That result |
| Android, after a process restart, `context` passed | The persisted result, if one exists |
| Nothing has completed | `null` / `nil` |
