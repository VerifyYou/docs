---
title: "init()"
description: "Optional. Set an appBase override once, for dev or staging builds."
---

## Signature

<CodeGroup>

```kotlin Android
fun initialize(appBase: String = VerifyYou.DEFAULT_APP_BASE)
```

```swift iOS
static func initialize(appBase: URL = defaultAppBase)
```

```ts React Native
function init(config?: InitConfig): void;

interface InitConfig {
  appBase?: string;
}
```

</CodeGroup>

Optional, on every platform. There is nothing else to configure: no key, ever, on any of the three SDKs. Skip calling this entirely if you are shipping against production.

## Options

<ParamField path="appBase" type="string" default="https://app.verifyyou.com">The hosted flow's own origin. Override it for a dev or staging build, the same as the browser SDK's `appBase`. It must be an `https` VerifyYou origin, or a local dev host: Android throws `IllegalArgumentException`, iOS fails an assertion and keeps the previous value, React Native throws.</ParamField>
